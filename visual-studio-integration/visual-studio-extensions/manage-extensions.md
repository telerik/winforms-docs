# Manage Extensions

**Progress Telerik UI for WinForms Extensions** can be installed / enabled / disabled by the **Extensions** menu in Visual Studio. It is necessary to select the **Manage Extensions** menu item: 

![Visual Studio Manage Extensions dialog for installing Telerik UI for WinForms Extensions](images/manage-extensions001.png)

If the Extension is already installed you can enable or disable it:

>caption Enable UI for WinForms Extension

![Visual Studio Manage Extensions dialog with Telerik UI for WinForms Extension enabled](images/manage-extensions002.png)


>caption Disable UI for WinForms Extension

![Visual Studio Manage Extensions dialog with Telerik UI for WinForms Extension disabled](images/manage-extensions003.png)

On the right side you have information about the specific **Version** of the Extension. If the version is not the desired one, you can uninstall the extension first by using the corresponding button:

![Visual Studio Manage Extensions dialog showing the installed Telerik UI for WinForms Extension version and uninstall command](images/manage-extensions004.png)

Then, you can install a newer version by searching in the Online section of the dialog:


![Visual Studio Manage Extensions Online tab showing Telerik UI for WinForms Extensions available to install](images/manage-extensions005.png)
