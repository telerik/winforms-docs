# Video Onboarding

Telerik UI for WinForms offers a comprehensive [video getting started course](https://www.telerik.com/support/video-courses) available to all developers. This class is designed to help you get started with the Telerik UI for WinForms components and features. It aims to put you in the shoes of an engineer who adds new features to an existing application.

{% include cta-panel-introduction.html %}
{% endif %}

The course starts with an introduction to the Telerik UI for WinForms components and its benefits. The training flow then takes you to an overview of the demo application and further, you get into creating inputs, data grids, charts, document viewers, and more. The course also talks about how to enhance the components with one of the built-in themes and/or by customizing the default styles.

Additionally, you will learn about other important Telerik UI for WinForms built-in features, such as globalization, localization, and accessibility, as well as options for reporting.

## Onboarding Modules

The [Telerik UI for WinForms technical online training](https://www.youtube.com/playlist?list=PLvmaC-XMqeBYZUfnE5_lSGtGAsEynVL4C) has an approximate duration of 2 hours and is split into eight modules with the following learning path:

Each chapter below includes written guidance for its learning topics.

* **Chapter 1: Introduction to Telerik UI for WinForms: Best Practices and Prerequisites** (Course overview, best practices, benefits of Telerik UI for WinForms, prerequisites). Written lessons: explore the [product overview]({%slug winforms/overview%}) and review the [First Steps prerequisites]({%slug winforms/getting-started/first-steps%}#prerequisites).
* **Chapter 2: Getting Started with Telerik UI for WinForms** (Create sample application). Written lesson: [create your first Telerik UI for WinForms application]({%slug winforms/getting-started/first-steps%}).
* **Chapter 3: From Input Components to Spreadsheet and Styling with Telerik UI for WinForms** (explore how to integrate essential input components, additional UI controls, and the Spreadsheet component). Written lessons: [add a RadTextBox input]({%slug winforms/editors/textbox/getting-started%}), [add RadSpreadsheet and its ribbon]({%slug radspreadsheet-getting-started%}), and [apply built-in themes]({%slug winforms/themes/using-default-themes%}).
* **Chapter 4: Mastering Telerik UI for WinForms Charts: From Basics to Advanced Features** (Working with charts in order to visualize data). Written lesson: [set up RadChartView and connect it to data]({%slug winforms/chartview/getting-started%}).
* **Chapter 5: Setting up Telerik UI for WinForms Grid and Key Features** (Working with data grid and key features). Written lessons: [get started with RadGridView]({%slug winforms/gridview/getting-started%}) and explore the [GridView key features and their linked guides]({%slug winforms/gridview%}#key-features).
* **Chapter 6: Implementing Scheduler Functionality in Telerik UI for WinForms** (Working with scheduler component to plan tasks and meetings). Written lessons: explore [RadScheduler and its scheduling features]({%slug winforms/scheduler%}) and [add scheduler navigation]({%slug winforms/scheduler/scheduler-navigator/getting-started%}).
* **Chapter 7: Building Reports in Telerik UI for WinForms** (Working with the report viewer component). Written lesson: [add a Telerik ReportViewer to a WinForms application]({%slug telerik-reporting-overview%}).
* **Chapter 8: Customizing Themes in Telerik UI for WinForms** (Applying Telerik themes and customizing Telerik components). Written lessons: [apply built-in themes]({%slug winforms/themes/using-default-themes%}) and [use custom themes]({%slug winforms/themes/using-custom-themes%}).
